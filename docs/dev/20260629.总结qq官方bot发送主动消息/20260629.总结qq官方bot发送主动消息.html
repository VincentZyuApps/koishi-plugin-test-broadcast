20260629 总结：QQ 官方 Bot 主动消息发送

基于 test-broadcast、openclaw-qqbot、koishi、koishi-doc、koishi-plugin-adapter-qq-crack 的本地源码分析。

核心结论

platform=qqQQ 群 / C2C 单聊

普通 QQ 群和 C2C 私聊走开放平台 v2 接口。

目标接口
QQ群POST /v2/groups/{group_openid}/messages
C2C 单聊POST /v2/users/{openid}/messages

platform=qqguildQQ 频道

QQ 频道使用频道接口，不要和普通 QQ 群 openid 混用。

目标接口
子频道POST /channels/{channel_id}/messages
频道私信POST /dms/{guild_id}/messages
普通 QQ 群主动消息填的是 group_openid，不是传统 QQ 群号。C2C 私聊填的是用户 openid，不是 QQ 号。

Python 直接调用 API

import requests

APP_ID = "你的AppID"
SECRET = "你的Secret"

token_resp = requests.post(
    "https://bots.qq.com/app/getAppAccessToken",
    json={"appId": APP_ID, "clientSecret": SECRET},
    timeout=30,
)
token_resp.raise_for_status()
access_token = token_resp.json()["access_token"]

headers = {
    "Authorization": f"QQBot {access_token}",
    "Content-Type": "application/json",
}

group_openid = "GROUP_OPENID"
resp = requests.post(
    f"https://api.sgroup.qq.com/v2/groups/{group_openid}/messages",
    headers=headers,
    json={
        "msg_type": 0,
        "content": "主动群消息测试",
    },
    timeout=30,
)

print(resp.status_code, resp.text)

msg_id / msg_seq 的区别

源码里被动回复会带 msg_id、msg_seq、event_id。这些主要用于回复用户刚发来的消息，或处理平台要求的消息序号。

主动消息不一定需要这些字段。openclaw-qqbot 的主动发送只构造下面两种 body。

文本

{
  "content": "文本",
  "msg_type": 0
}

Markdown

{
  "markdown": {
    "content": "Markdown 内容"
  },
  "msg_type": 2
}

常见坑

问题说明
group_openid 不是 QQ 群号 QQ 官方 Bot 群接口要填群 openid，不能填 OneBot 使用的真实 QQ 群号。
openid 不是 QQ 号 C2C 主动私聊要填用户 openid，不能填 QQ 号。
qq 和 qqguild 不要混用 qq 使用 /v2/groups 和 /v2/users；qqguild 使用 /channels 和 /dms。
Markdown 权限 adapter 支持 Markdown 写法，但最终是否成功仍受 QQ 官方 Bot 权限、审核、灰度能力影响。

推荐落地方式

在 Koishi 插件内，优先使用通用发送接口：

await bot.sendMessage(groupOpenid, content)

如果要发 QQ 官方 Markdown，用：

await bot.sendMessage(groupOpenid, h('qq:rawmarkdown-without-keyboard', {
  content,
}))

如果 Koishi 编码器不满足需求，再 fallback 到：

await bot.internal.sendMessage(groupOpenid, {
  msg_type: 2,
  markdown: { content },
})

如果完全脱离 Koishi，直接调用官方 API：

POST /v2/groups/{group_openid}/messages
Authorization: QQBot ACCESS_TOKEN
