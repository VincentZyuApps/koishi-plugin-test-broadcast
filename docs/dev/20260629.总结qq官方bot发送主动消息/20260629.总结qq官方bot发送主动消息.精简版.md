# QQ 官方 Bot 主动消息发送精简版

基于 `test-broadcast`、`openclaw-qqbot`、`koishi-plugin-adapter-qq-crack` 源码整理。

## 1. 先分清目标平台

| Koishi 平台 | 目标 | 官方接口 |
| --- | --- | --- |
| `qq` | 普通 QQ 群 | `POST /v2/groups/{group_openid}/messages` |
| `qq` | C2C 单聊 | `POST /v2/users/{openid}/messages` |
| `qqguild` | QQ 频道子频道 | `POST /channels/{channel_id}/messages` |
| `qqguild` | QQ 频道私信 | `POST /dms/{guild_id}/messages` |

关键点：`group_openid` 不是 QQ 群号，`openid` 不是 QQ 号。OneBot 用真实群号，QQ 官方 Bot 用 openid。

## 2. 获取 AccessToken

```bash
curl -X POST "https://bots.qq.com/app/getAppAccessToken" ^
  -H "Content-Type: application/json" ^
  -d "{\"appId\":\"你的AppID\",\"clientSecret\":\"你的Secret\"}"
```

后续请求头：

```http
Authorization: QQBot ACCESS_TOKEN
Content-Type: application/json
```

## 3. curl 直接发普通 QQ 群

文本：

```bash
curl -X POST "https://api.sgroup.qq.com/v2/groups/GROUP_OPENID/messages" ^
  -H "Authorization: QQBot ACCESS_TOKEN" ^
  -H "Content-Type: application/json" ^
  -d "{\"msg_type\":0,\"content\":\"主动群消息测试\"}"
```

Markdown：

```bash
curl -X POST "https://api.sgroup.qq.com/v2/groups/GROUP_OPENID/messages" ^
  -H "Authorization: QQBot ACCESS_TOKEN" ^
  -H "Content-Type: application/json" ^
  -d "{\"msg_type\":2,\"markdown\":{\"content\":\"# 主动消息测试\"}}"
```

## 4. curl 直接发 C2C 单聊

```bash
curl -X POST "https://api.sgroup.qq.com/v2/users/USER_OPENID/messages" ^
  -H "Authorization: QQBot ACCESS_TOKEN" ^
  -H "Content-Type: application/json" ^
  -d "{\"msg_type\":0,\"content\":\"主动私聊测试\"}"
```

## 5. Python 直接调用

```python
import requests

r = requests.post(
    "https://bots.qq.com/app/getAppAccessToken",
    json={"appId": "你的AppID", "clientSecret": "你的Secret"},
    timeout=30,
)
token = r.json()["access_token"]

resp = requests.post(
    "https://api.sgroup.qq.com/v2/groups/GROUP_OPENID/messages",
    headers={"Authorization": f"QQBot {token}", "Content-Type": "application/json"},
    json={"msg_type": 0, "content": "主动群消息测试"},
    timeout=30,
)
print(resp.status_code, resp.text)
```

## 6. Koishi 内推荐写法

普通群消息：

```ts
const bot = ctx.bots.find(bot => bot.platform === 'qq')
await bot.sendMessage(groupOpenid, '主动群消息测试')
```

QQ Markdown：

```ts
import { h } from 'koishi'

const bot = ctx.bots.find(bot => bot.platform === 'qq')
await bot.sendMessage(groupOpenid, h('qq:rawmarkdown-without-keyboard', {
  content: '# 主动消息测试',
}))
```

直接调 adapter internal：

```ts
const bot = ctx.bots.find(bot => bot.platform === 'qq') as any

await bot.internal.sendMessage(groupOpenid, {
  msg_type: 2,
  markdown: { content: '# 主动消息测试' },
})
```

## 7. 源码对应关系

- `openclaw-qqbot/src/api.ts`：封装 token、`/v2/groups`、`/v2/users`、`/channels`、`/dms`。
- `koishi-plugin-adapter-qq-crack/src/internal/group.ts`：`sendMessage` 映射到 `/v2/groups/{channel.id}/messages`。
- `koishi-plugin-adapter-qq-crack/src/message.ts`：群走 `internal.sendMessage()`，私聊走 `internal.sendPrivateMessage()`。
- `test-broadcast/src/qq.ts`：Markdown 优先走 `h('qq:rawmarkdown-without-keyboard')`，失败 fallback 到 `internal.sendMessage()`。

## 8. 最短结论

Koishi 插件里优先用：

```ts
await bot.sendMessage(groupOpenid, content)
```

要脱离 Koishi 就直接调用：

```http
POST https://api.sgroup.qq.com/v2/groups/{group_openid}/messages
Authorization: QQBot ACCESS_TOKEN
```
